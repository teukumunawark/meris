# Glossary

## Session
An ephemeral, zero-account group expense sharing activity created by a User (the Payer) to split costs proportionally with other Participants.

## Participant
A member of a Session who can join via a unique Session ID, select or claim their shared items, and view their proportional total owed.

## Theme
The visual presentation mode of the Meris user interface:
- **Dark Mode**: The default slate-charcoal aesthetic optimized for low-light conditions.
- **Light Mode**: A soft warm-gray/alabaster aesthetic designed for optimal readability in high-ambient-light environments.
